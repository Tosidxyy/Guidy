## 1. 设计论点（Art Direction）

**选定意象：晨光时间轴**（PRD 候选之一，关闭待评审点 5）。

> 时间不是格子，是一条被晨光照亮的路。Guidy 把"自律"从冷冰冰的打卡表，变成一天中光线推移的旅程：日历是主角，块是路上的驿站，AI 对话是清晨的同行者。

三条视觉决策：

1. **日历即舞台**：工作台右栏 62% 给日历，纸感暖白底 + 细腻时间刻度，块用分类色"透光"渲染（色相 12% 透明度叠底），像光透过彩色玻璃落在时间轴上。
2. **晨光作为品牌时刻**：琥珀→珊瑚→靛紫的黎明渐变只出现在少数关键处——Logo、当前时间线、"确认并生成"主 CTA、流式光标、官方模板徽章。日常界面保持克制（PRD §7：动效服务状态反馈，不炫技）。
3. **对话有温度，数据有秩序**：左栏对话面板用暖纸底 + 柔和气泡；右栏日历用冷白底 + 精确刻度。两栏色温差暗示"感性表达 → 理性落位"的产品核心。

**反模板承诺**：不用通用 SaaS 蓝白灰；社区卡片带"一周节奏条"（§6.6）这一学科专属签名元素；空状态是定制晨光地平线插画而非通用图标。

## 2. 色彩系统

### 2.1 品牌与晨光渐变

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--site-brand` | `#4C6EF5`（靛蓝） | 主操作、链接、选中环、信息语义 |
| `--site-brand-ink` | `#FFFFFF` | 主按钮文字 |
| `--site-dawn` | `linear-gradient(135deg,#FFB86B 0%,#FF7E5F 45%,#6A5AE0 100%)` | Logo / 主 CTA / 当前时间线点 / 流式光标 / 官方徽章 |
| `--site-dawn-soft` | 同渐变 8% 透明度 | 今日列底色、卡片 hover 光晕 |

### 2.2 分类色板（8 色，色盲双编码：颜色 + 图标 + 明度分层）

| 分类 | 色值 | 明度层 | lucide 图标 |
| --- | --- | --- | --- |
| study 学习 | `#4C6EF5` | 深 | `book-open` |
| fitness 健身 | `#2F9E6E` | 中 | `dumbbell` |
| reading 阅读 | `#D98E04` | 中亮 | `library` |
| work 工作 | `#0E8A9E` | 中深 | `briefcase` |
| life 生活 | `#E2694F` | 中亮 | `home` |
| creative 创造 | `#9C5BD1` | 中 | `palette` |
| rest 休息 | `#7C8AA0` | 浅 | `moon` |
| other 其他 | `#8C7A6B` | 中浅 | `shapes` |

块渲染公式：背景 = 分类色 12% 叠 surface；左轨 3px 实色；边框 = 分类色 30%；文字用 ink（不用分类色做正文，保证对比度）。深/浅模式下分类色不变，透明度叠底自动适配。

### 2.3 语义色

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--site-success` | `#2F9E6E` | 成功 / diff 新增 |
| `--site-warning` | `#D98E04` | 妥协项 / 软约束违反 / diff 移动 |
| `--site-danger` | `#D64545` | 硬冲突 / 删除 / diff 删除 |
| `--site-info` | `#4C6EF5` | 提示 |

### 2.4 中性色（暖冷分离）

| 令牌 | Light | Dark | 用途 |
| --- | --- | --- | --- |
| `--site-bg` | `#F7F5F0`（暖纸） | `#13151B` | 页面底 / 对话栏底 |
| `--site-surface` | `#FFFFFF`（冷白） | `#1B1E26` | 日历底 / 卡片 |
| `--site-surface-2` | `#F1EEE7` | `#232733` | 次级面 / 骨架 / hover |
| `--site-ink` | `#232733` | `#EDEEF2` | 正文 |
| `--site-ink-soft` | `#5C6270` | `#9AA0AE` | 次级文字 / 时间刻度 |
| `--site-line` | `#E4DFD5` | `#2E3340` | 边框 / 小时线 |
| `--site-line-soft` | `#EFEAE1` | `#262B36` | 半小时虚线 |
| `--site-scrim` | `rgba(35,39,51,.45)` | `rgba(0,0,0,.6)` | 抽屉遮罩 |

对比度校验（Light）：ink/bg 12.8:1；ink-soft/surface 5.9:1；brand/surface 4.6:1；danger/surface 4.8:1；warning 文字需加深 `#A66A00` 用于小字（图形可用原值）。全部 ≥4.5:1。

## 3. 字体与排版

| 角色 | 字体栈 | 说明 |
| --- | --- | --- |
| Display / 数字 | `"Space Grotesk", "Inter", sans-serif` | 计时器般的几何数字；日历时间、倒计时、统计数字一律 `font-variant-numeric: tabular-nums` |
| Body | `"Inter", "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", sans-serif` | 中文回退系统字体，不加载中文 webfont（体积） |

字号阶：12（刻度/角标）/ 13（块标题/次级）/ 14（正文）/ 16（强调）/ 20（抽屉标题）/ 28（页面标题）/ 40（空状态标语，Space Grotesk）。行高：正文 1.6，块内 1.3。字重：400/500/600，不用 700 以上（克制）。

## 4. 设计令牌（Nudge 契约）

落地于 `src/globals.css`，全部经 `--site-*` 消费，禁止硬编码绕过：

```
外观：--site-bg / surface / surface-2 / ink / ink-soft / line / line-soft / scrim
      --site-brand / brand-ink / dawn / dawn-soft
      --site-success / warning / danger / info
      --site-cat-study … --site-cat-other（8 个）
圆角：--site-radius-s: 6px / -m: 10px / -l: 16px（块固定 8px）
间距：--site-space: 4px（倍数派生：8/12/16/24/32/48）
字体：--site-font-display / --site-font-body
动效：--site-motion-quick: 120ms / -standard: 200ms / -slow: 320ms
      --site-ease-glide: cubic-bezier(.22,1,.36,1)
      --site-ease-snap: cubic-bezier(.34,1.56,.64,1)
```

**设计工作台注册能力**（`open_design_workbench` 声明，仅声明已实现者）：`appearance`（明暗 + 品牌色相）、`radius`、`spacing`、`typography`、`motion`。页面注册：`workbench`（/）、`community`（/community）、`template-detail`（/template/:id）。

## 6. 核心组件规格

### 6.1 顶栏

固定不随滚动（工作台无页面滚动，两栏各自内滚）。Logo：SVG 晨光标记（半圆日出 + 一条水平时间线穿过）+ "Guidy" Space Grotesk 600。计划标题可点击打开计划列表抽屉。视图切换为分段控件（周/日）。社区入口带小圆点提示（有新官方模板时，P2）。

### 6.2 对话面板

| 元素 | 规格 |
| --- | --- |
| 用户气泡 | 右对齐，ink 底 + 反色文字，radius-l，最大宽 85% |
| AI 气泡 | 左对齐，surface 底 + line 边框，Markdown 净化渲染；头像为晨光标记 20px |
| 流式光标 | 末尾 2px 宽竖条，dawn 渐变，1s 呼吸；`prefers-reduced-motion` 时常亮 |
| 追问 | AI 气泡内编号问题 ≤2，下方快捷回复 chips（可选） |
| 输入框 | surface-2 底，radius-m，autosize 1–5 行；发送按钮 brand 实色；⌘/Ctrl+Enter 发送；超限字符计数变 danger |
| 场景 chips（P1） | 输入框上方横滑：备考冲刺 / 健身塑形 / 阅读习惯 / 周生活管理 |
| 配额提示 | 剩余 ≤10 轮时输入框上方出现 ink-soft 小字 |

### 6.3 约束确认卡（F1.3，核心转化组件）

```
┌ 我理解到的约束 ─────────────── 5 条 ┐
│ 🕒 每天最多学习 6 小时        [AI] ✎ ✕ │
│ 🚫 周三 18:00–22:00 兼职     [你] ✎ ✕ │
│ ↔️ 数学与英语不连续学  [软|硬]      ✎ ✕ │
│ 🌅 背单词偏好早晨            [AI] ✎ ✕ │
│ 📌 12/20 考研初试（倒计时 34 天）     │
│ ＋ 补充约束                          │
│            [ 确认并生成 ✦ ]（dawn 渐变）│
└──────────────────────────────────────┘
```

- 行结构：类型图标（色方底）+ 人话描述 + 来源标签（AI 提取/你说的）+ 编辑/删除。
- mutex 行内嵌软/硬分段开关；编辑打开行内表单（不跳抽屉）。
- 确认按钮为全应用唯一 dawn 渐变实色 CTA（品牌时刻）；点击后按钮转 loading，日历侧同步骨架。
- 卡片可整体折叠为"已确认 5 条约束 ✎"摘要条。

### 6.4 生成预览 / diff 卡（F5.2）

- 预览卡：标题"为你排好了一周" + 统计（N 个任务块 · M 小时 · 0 冲突）+ 妥协项列表（warning 点）+ [放弃] [应用到日历]。
- diff 卡：summary 一句话 + 图例 chips（绿新增/红删除/黄移动）+ 受影响块列表（可点击定位日历）+ [放弃] [应用改动]。
- 日历同步：新增块绿色虚线 ghost、删除块红色半透明 + 删除线、移动块黄色 ghost 在新位 + 旧位残影；确认后 ghost 以 ease-snap 落位（200ms 轻微过冲）。

### 6.5 日历面板（视觉主角）

**网格**：时间槽 56px；小时线 line 实线、半小时 line-soft 虚线；刻度 Space Grotesk 12 tabular；今日列 dawn-soft 底 + 日期数字 dawn 渐变圆 pill；周末列 surface-2 微染。

**当前时间线**：珊瑚 `#FF7E5F` 1.5px 横线贯穿今日列，左端 6px 圆点 + 时间 chip（Space Grotesk 11）；每分钟更新。

**块解剖**（最小高 22px）：

```
┌▌──────────────────────┐
│▌ 📖 数学真题      ● 📌 │  ← 左轨 3px 分类色；图标 12；标题 13/500
│▌ 08:00–10:00 · 2h     │  ← 时间 11 tabular ink-soft；优先级点（高=danger实/中=warning实/低=空心）
└▌──────────────────────┘
```

**块状态表**：

| 状态 | 视觉 |
| --- | --- |
| default | 分类色 12% 底 + 30% 边框 |
| hover | 边框升 60% + shadow-s + 上浮 1px |
| selected | 2px brand 外环（offset 2） |
| dragging | scale 1.02 + shadow-l + opacity .92；原槽位虚线残影；落点时间 chip 跟随 |
| invalid-drop | danger 边框 + 240ms 抖动 + 原因气泡（禁止释放） |
| soft-warn | warning 虚线边框 + 角标 ⚠（允许释放） |
| pinned | 📌 图标常显 + 左轨加粗 4px |
| ghost-new / ghost-old / ghost-move | 见 §6.4 |
| compromise | 右上角 warning 小三角，汇总条可定位 |

**汇总条**（日历顶）："0 处冲突 · 2 处妥协"；冲突>0 时 danger 底；点击展开列表并定位块。

**拖拽吸附**：15min 网格；拖动中落点 chip 显示"周四 08:15–10:15"；跨天拖动时目标列高亮 dawn-soft。

**迷你月历**（P1）：右下浮动 220px，今日 dawn 点，有计划日落小色点。

### 6.6 社区广场（/community）

- 头部：标题"社区模板" + 搜索框 + 排序分段（最新/最热）+ 标签横滑 chips。
- **卡片签名元素——一周节奏条**：7 根竖条（周一→周日），高度=当日任务总分钟归一化，条内按分类色堆叠分段；28px 高，一眼看出模板的"节奏形状"。这是 Guidy 社区的专属视觉语言，竞品没有。
- 卡片结构：标题 16/600 → 描述 2 行截断 → 节奏条 → 标签 chips → 统计行（`users` 使用数 · `heart` 点赞数）；官方模板左上角 dawn 渐变描边徽章"官方示例"。
- hover：整卡上浮 2px + dawn-soft 光晕边框；点击进详情。
- 空状态：定制插画 + "还没有模板，成为第一个分享者" + [去规划]。

### 6.7 模板详情（/template/:id）

只读周日历（复用日历组件，interactive=false，块不可拖）+ 约束清单（分组、suggested 标记"建议，套用后可改"）+ 作者说明 + 统计 + 吸底 CTA [套用模板]（brand 实色）。套用后跳转工作台并自动打开对话，注入引导语"说说你的忙碌时段，我来按你的情况重排"。

### 6.8 抽屉体系

右侧 420px（移动全屏），scrim 遮罩，ease-glide 240ms 滑入。约束清单按类型分组（图标+计数），行内编辑/启用开关/删除；修改后底部浮出"重新排程预览"按钮（触发本地引擎试算→diff 卡）。计划列表：卡片行（标题/范围/块数/更新时间），当前计划 brand 左轨；新建/重命名/删除（删除 toast 可撤销）。设置：外观（明暗/品牌色相/圆角/间距/动效开关，即 Nudge 项）、导出（.ics/JSON）、恢复码、删除全部数据（danger 区，二次确认输入 DELETE）。

## 7. 动效规格

| 交互 | 时长/缓动 | 说明 |
| --- | --- | --- |
| 块落位（确认/拖拽释放） | 200ms ease-snap | 轻微过冲，"驿站落定"感 |
| 块 hover/选中 | 120ms ease-glide | 边框/阴影/环 |
| 冲突抖动 | 240ms keyframes ±3px | 仅 invalid-drop 触发一次 |
| ghost 显隐 | 200ms ease-glide | 透明度+缩放 .98→1 |
| 抽屉/面板 | 240ms ease-glide | 位移+透明度 |
| 流式光标 | 1s 呼吸循环 | dawn 渐变 |
| 骨架 shimmer | 1.4s 循环 | surface-2→line 渐变扫过 |
| 页面路由切换 | 200ms 淡入 | 不做花哨转场 |
| 当前时间线 | 每分钟位移 | 无动画跳变 |
| 社区卡片入场 | 交错 40ms 淡入上浮 | 首屏 ≤8 张，仅首次 |

**总原则**：拖拽路径上零 JS 动画（纯 transform）；所有循环动效在 `prefers-reduced-motion: reduce` 下停止，状态变化保留即时透明度切换；动效总预算克制——界面安静，反馈清晰。

## 9. 可访问性

- **键盘地图**：`/` 聚焦对话输入；`Tab` 遍历块（roving tabindex）；方向键移动选中块 15min，`Shift+方向键` 跨天；`Enter` 详情；`Delete` 删除（undo toast）；`Ctrl+Z / Ctrl+Shift+Z` 撤销/重做；`Esc` 关抽屉/取消拖拽/取消预览。
- 焦点环：2px brand，offset 2，全交互元素可见。
- 块为 `role="button"` + `aria-label="数学真题，周四 8点到10点，高优先级，已钉住"`；拖拽有 `aria-grabbed` 与键盘替代（A11y 要求）。
- 色彩双编码：分类=色+图标；冲突=色+图标+文字；diff=色+图例文字。
- 对比度 ≥4.5:1（§2.4 已校验）；warning 小字用加深色 `#A66A00`。
- 流式区域 `aria-live="polite"`；确认卡为 `role="dialog"` 焦点陷阱。
- 触控目标 ≥44×44px（移动端块最小高提升至 32px + 间距补偿）。

## 10. 文案语气

简短、具体、温和坚定；不喊口号、不鸡汤、不用感叹号堆砌。错误说清"发生了什么 + 怎么办"。

| 场景 | 文案 |
| --- | --- |
| 首屏引导 | 说说你的目标和时间安排，我来帮你排。 |
| 配额耗尽 | 今天的对话额度用完了，明天再来继续规划。 |
| 硬冲突 | 周三 18:00–22:00 被兼职占用，数学真题放不下。可以把数学挪到周四上午，或缩短到 90 分钟。 |
| 无解报告 | 这一周放不下全部任务：每日 2 小时上限，但任务共需 10 小时。建议放宽上限到 4 小时，或减少 2 个任务。 |
| 发布脱敏预览 | 已移除具体日期和个人备注，只保留计划结构。 |
| 删除确认 | 这会删除你的全部计划、对话和模板，无法恢复。输入 DELETE 确认。 |
| 重连 | 已重连，进度已恢复。 |

## 11. 图标与资产

- 图标统一 lucide-react，16px 常规 / 12px 块内 / 20px 导航；约束类型图标：busy=`calendar-x`、active=`sun`、daily_cap=`gauge`、mutex=`arrow-left-right`、preferred=`sparkles`、buffer=`space`（`move-horizontal`）、fixed=`pin`、deadline=`flag`。
- **定制 SVG 资产**（不用图库照片）：
  1. `logo.svg`：半圆日出 + 水平时间线，dawn 渐变。
  2. `empty-calendar.svg`：晨光地平线——远山剪影 + 升起半日 + 一条虚线路径穿过 3 个 ghost 驿站块。
  3. `empty-community.svg`：多块彩色驿站拼成的小径。
  4. `favicon.svg`：logo 简化 32px。
- 颗粒感：仅对话面板头部用 3% opacity CSS noise（SVG feTurbulence data-uri），日历区保持纯净。
- 不引入外部图片/字体文件（Space Grotesk / Inter 走 fontsource npm 自托管，subset latin）。
