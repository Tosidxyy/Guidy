# 排程预览内核（首批）

`backend/src/scheduling/preview.ts` 提供纯函数 `previewSchedule`。聊天已接首批具体时段核对与首阶段各项一次试排，通过既有 messages API 保存私有对话产物；尚未接真实日历或批准入历服务，不是完整 M2。

## 输入边界

- 上游必须明确任务实例、时长、依赖、UTC epoch 毫秒时间窗及 IANA 时区。每周频次、尝试每周60分钟、阶段编号不能自动变成具体日期或真实空闲时间。
- `schema_version=1`；每类列表最多100项，预览跨度最多31天。窗口可为空，空窗口返回未安排；非法输入、未知依赖、环、重复身份/依赖整体拒绝。
- 任务可带 earliest/deadline/fixed_start、series_id 和 minimum_gap_minutes。系列间隔从前一实例结束到后一实例开始，采用双方较大的间隔；所有任务占用同一用户的时间。
- completed_dependencies 只接已验证的历史完成时刻，不能来自通知送达或模型推测；不得晚于预览起点。上游负责 owner、真实日历快照、来源确认与版本一致性；本内核不做身份认证。
- 本地时间转换、DST歧义/不存在的时刻、重复规则展开、阶段周期、资源互斥及领域额外约束尚未实现。IANA 名称必须有效；UTC具体时刻由上游确认，不能用固定 UTC+8 替代时区。

## 算法与结果

先合并重叠/相邻窗口，再按稳定任务身份顺序选择依赖已处理的任务。在合法窗口中跳过已有占用和拟安排，选择最早能容纳整个任务的位置；不拆分任务，起止采用半开区间，结束时刻可紧接下一任务。

结果固定 `status=preview_only`、`strategy=stable_topological_earliest_v1`，包含 placements 和 unplaced。后者区分依赖未安排与无合法时间窗。没有合法位置时不会挪动固定时间、越过截止时间或捏造空闲。

这是有界贪心算法，不保证最优，也不保证发现所有可行解；较早任务可能占用较后固定任务的位置。不能把 `no_legal_window` 表述为数学上不存在方案。备选安排、优化与更细冲突解释待后续实现。输入和旧数据不修改，成功预览也不代表已确认、已入历或提醒已安排。

## 验证及下一步

自动测试覆盖占用/半开边界、依赖与环、固定时间/截止/不拆分、间隔、跨日、DST真实时长、无窗口、畸形输入及40组合法性检查。DST测试只证明 UTC 时刻的时长处理，不证明自然语言本地时间转换。

真实日历占用、完整约束、独立不可变预览表和批准事务仍需逐项实现。参见 [架构](ARCHITECTURE.md)、[数据库](DATABASE.md)、[进度](TODO.md)。

## 聊天试排协议（schedule-chat-v1）

在已生成的聊天草稿点击「预览首阶段具体时间」，Agent询问具体日期与时区。用户可直接回复 `可用时段：北京时间，2026-10-20 20:00-21:00；2026-10-22 20:00-21:00`；日期应换为未来31天内。首批仅支持明确的北京时间/Asia/Shanghai或UTC、最多7个不重叠的同日时段，24:00、无效日期、跨日文字、其他时区与附带命令不猜测。北京时间当前未来窗口转换为UTC，并保留IANA时区；这不是全时区/DST转换器。

受控解析成功后在聊天展示待核对时段，未运行排程。用户「确认时段并预览」发送固定确认文字，只能确认紧邻的最新提议，服务端绑定本人Goal、当前草稿源、Goal/审阅版本与原始回复run。冻结最早阶段的任务稳定身份/标题/时长/依赖，首阶段各项一次，不展开周频次，不猜测阶段周期/休息间隔/资源/截止要求；范围外依赖不冒充已完成。

确认后内核以声明窗口计算，busy为空，明确标记尚未检查真实日历占用及完整领域约束。拟安排/未安排原因保存在新的成功agent run，只读保留旧记录；没有更新Goal/Slot/PlanVersion/日历/提醒。每Goal最多40次该类消息，不调用模型/搜索/邮件、不占模型澄清或方案生成配额；含糊回复在时段问答内仍给受控指导，普通模型聊天保持原额度。

同键同内容重放只读旧回执；错版本/并发聊天不插入。提议/确认的INSERT再次校验最新草稿及审阅版本；条件改变、另端审阅、新生成源或时段过期拒绝旧确认。GET返回过期标志，旧记录保留，界面禁用非紧邻/过期提议；用户提供新时段后需重新核对。确认按钮保留尚未发送的输入。适用性风险历史持续阻断试排，关键词仅首批保守防护，不是完整领域安全审查。

聊天入口、核对卡、拟安排卡沿用Agent/草稿黑白视觉；不新增字段表单或导航。步骤改写、每周完整重复实例、通用自然语言日期、实际占用和方案批准仍在后续范围。
